# Verano Estate - State Verano By

## Formulario Clientes Digital

This repository contains the digital forms for Verano Estate by Chef Franko.

### Files

- `index.html` - Simple contact form with language toggle
- `guest-form.html` - Complete guest information form for Verano Estate
- `HTML-MENU.html` - Interactive menu selection form
- `untitled-1.html` - Wedding culinary control panel

### Features

- Bilingual forms (Spanish/English)
- WhatsApp integration for form submissions
- Responsive design
- Guest information collection
- Room assignment tracking
- Provision and amenity requests

### Usage

Open any HTML file in a web browser to use the forms. The forms integrate with WhatsApp for easy submission to the Verano Estate team.
